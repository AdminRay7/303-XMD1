Authentication

Get your API key from the dashboard

Pass it in any of these ways:

OPTION 1 — AUTHORIZATION HEADER
Authorization: Bearer xmd_xxxxxxxxxxxxxxxx
OPTION 2 — QUERY PARAMETER
https://your-domain.com/api/v1/me?key=xmd_xxxx
OPTION 3 — CUSTOM HEADER
x-api-key: xmd_xxxxxxxxxxxxxxxx

Quick Start

Send your first message

curl -X POST https://your-domain.com/api/v1/send \
  -H "Authorization: Bearer xmd_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "sessionId": "sess_abc123",
    "to": "254712345678",
    "text": "Hello from the API"
  }'

Errors

All errors return {"error": "..."}

// 401 — invalid key
{ "error": "Invalid or revoked API key" }

// 403 — banned or admin-only
{ "error": "Account is banned" }

// 429 — rate limited
{ "error": "Rate limit exceeded" }
